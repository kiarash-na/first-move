# Deliverables: final prototype and demo

> At the end of the development sprint, teams should have a working prototype that can be demonstrated using the predefined project scenarios.
>
> The final presentation should focus on the developed tool and include a live demo of the Quick Check.
>
> Teams should briefly demonstrate:

- How users enter project data
- How the assessment is generated
- How the results are communicated
- How the tool helps users understand the main factors influencing the assessment

Slides (slide 5):

> Focus on a working and understandable implementation of the existing concept

> **DEMO IT LIVE:** Enter project data → Run the Quick Check → Explain the result → Show the report
