# Methodology preamble

> In the following default parameters, required user inputs and the assessment methodology to be used for the 5GDHC Quick Check Tool is described. They are intended for a preliminary screening rather than a detailed system design. The parameters, inputs and methodology are based on simplified assumptions and should be interpreted carefully. Actual values may vary depending on project-specific conditions and should be refined through further analysis.
