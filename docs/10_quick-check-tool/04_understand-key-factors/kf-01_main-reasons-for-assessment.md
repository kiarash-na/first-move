# Show the main reasons for the assessment

> In addition to the overall indicator, the tool should show the main reasons for the assessment, for example relevant technical and economic factors.

> For example, the overall result could look like this:

- Promising – High heat demand density, suitable local heat source available, Investment costs within predefined range

Slides (slide 4):

> **OVERALL ASSESSMENT:** Show the main drivers: e.g., heat-demand density, local heat sources and investment costs
