# Cooling-to-Heating Demand Ratio

> The cooling-to-heating ratio indicates how balanced the annual heating and cooling demands are. A value of 1 indicates equal heating and cooling demands, while values approaching 0 indicate an increasing imbalance. This indicator should be interpreted together with the other technical and economic indicators. An unbalanced demand profile does not automatically make a 5GDHC network unsuitable.
