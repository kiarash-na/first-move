# OQ-04 · Role of the "rural, sub-urban, urban" input

**Observation:** A categorical building density is listed as an input, while the exact building density is calculated. No use of, or mapping for, the category is given.

**Source quotes:**

- §2.1: "Building density (rural, sub-urban, urban)"
- §2.1: "Exact building density is calculated automatically from the total number of buildings and the project area."
