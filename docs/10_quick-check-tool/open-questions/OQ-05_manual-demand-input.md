# OQ-05 · Form of the optional manual demand input

**Observation:** Manual heating/cooling demand is an optional alternative; its granularity (total, per type/period) and unit are not specified.

**Source quotes:**

- §2.2: "If the user has more detailed information about the buildings' energy demand, manual input of heating and cooling demand should be available as an optional alternative to the default estimates."
