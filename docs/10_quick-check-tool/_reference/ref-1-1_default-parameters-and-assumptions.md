# Default Parameters and Assumptions

> To enable a quick and consistent assessment, the tool uses predefined default values for building energy demand, average floor area, and the potential energy supply from different sources. These values allow users to perform an initial assessment without having to provide detailed building-level data.
>
> Each building category is associated with default values for annual heating demand, annual cooling demand and average floor area. The applicable values depend on the building's construction period.

**See:** [building types](building-types.yaml)
