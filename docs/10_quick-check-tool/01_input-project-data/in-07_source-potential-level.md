# Source potential level

> For each selected source, they indicate its potential as:

- Low
- Medium
- High
- Unknown

> The tool assigns the corresponding predefined annual supply capacity and COP, where applicable.
>
> The tool should use the corresponding predefined values to estimate the annual heating and cooling supply potential.
