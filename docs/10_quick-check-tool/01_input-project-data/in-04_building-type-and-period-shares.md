# Building Type and Construction Period

> Users specify the relative share of each building type and construction period within the project area. The distribution can be entered in a table, with building types as rows and construction periods as columns. The sum of all shares must equal 100%. For example, a project area could consist of:

- 50% residential buildings constructed between 1991 and 2010
- 25% residential buildings constructed between 2011 and today
- 25% Category A buildings constructed between 2011 and today

> The tool uses these shares to estimate the number of buildings in each category and calculate their corresponding heating and cooling demand.
