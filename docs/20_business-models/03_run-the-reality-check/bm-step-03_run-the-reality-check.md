# 3 | Run the Reality Check

1. Use rough but transparent assumptions rather than detailed engineering calculations.
2. Test plausible connection rates, tariffs, capital expenditure, financing and subsidy dependencies.
3. Identify the top risks and top critical assumptions, including one potential deal-breaker.
4. Explain how each could be validated.

V01 wording:

- Identify the Top 3 risks and Top 3 critical assumptions, including one potential deal-breaker.
