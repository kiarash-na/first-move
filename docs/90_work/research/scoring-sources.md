# Scoring sources: verified bibliography for the Business Plan AI score

Access date for every web source: **2026-10-24**. Verification method: each DOI was resolved at `https://doi.org/<doi>` (final HTTP status recorded) and its metadata read from the Crossref API (title, authors, journal, volume, pages, year). Each URL was fetched through the session proxy with `curl -L` (final status and page or PDF title recorded). The content behind every cited claim was opened: a full text (PDF), an official abstract (publisher repository, RePEc/IDEAS, OpenAlex or an institutional repository), or the official web page. A quote in "double quotes" is verbatim from the opened text. Anything else is a close paraphrase and is marked "(paraphrase)".

Reliability classes: **provider** (challenge material in the repo) · **peer-reviewed** · **official** (government or public agency) · **standard** (a framework a public body issued) · **book** · **company** (practitioner or vendor material).

Status codes: `200` = opened. `DOI→200` = the DOI resolves to the publisher (status after redirects). `DOI→403` = the DOI resolves but the publisher blocks robots; the content was then read from the open copy named in the entry.
