## SEO: what was missing, now built

The site already had per-locale routes with `<html lang>`, per-page titles and descriptions,
static prerendering and `noindex` on the consent page. Missing, and built in this run:

- `lib/seo/`: the canonical origin (`SITE_URL`, falling back to `https://www.firstmove.energy`),
  per-locale URLs, hreflang maps with `x-default` at German (the unprefixed root only redirects,
  D-67, so it cannot be the target) and the shared Open Graph/Twitter shell. og:title and
  og:description stay unset there on purpose — Next inherits them from the page's title (template
  applied) and description.
- `app/robots.ts`: public pages allowed; `/en|de/dashboard`, `/en|de/mail/confirm` and `/api/`
  disallowed; points at the sitemap.
- `app/sitemap.ts`: every public page in both locales (landing, 9 docs pages, presentation, 6
  legal pages → 34 URLs), each with its hreflang alternates. The dashboard, the consent page and
  the API are absent on purpose.
- Canonical + hreflang + cards on every public page (the four root layouts, the legal helper, the
  docs and presentation pages); the dashboard app shell is `noindex, nofollow` (its data lives in
  the visitor's browser).
- `app/[lang]/opengraph-image.tsx`: the 1200×630 card per locale (ink, the cyan/orange network
  mark, IBM Plex Mono wordmark, localized slogan), rendered at request time. `app/apple-icon.tsx`:
  the 180×180 touch icon, prerendered.
- JSON-LD `WebApplication` on the landing, from the dictionaries.
- `e2e/seo.spec.ts`: six tests over robots, sitemap, the head tags, the image routes and the
  noindex dashboard.

### SEO decisions worth knowing

- The **opengraph-image file convention does not attach** its `<meta>` tags to pages across the
  route groups of the four root layouts, so `publicMetadata` names the image URL explicitly
  (`/{lang}/opengraph-image`). Verified live: tags emit, both locales answer PNG.
- Archivo ships woff2 only, which the image renderer cannot read — the card uses IBM Plex Mono.
- `app/apple-icon.tsx` draws the mark with plain boxes: the SVG's blur filter fails the renderer.
  The proxy matcher now skips `/apple-icon` — its generated URL has no dot, so the locale redirect
  ate it.
- The OG image route renders on demand (Cache Components keeps routes that read `params`
  dynamic); its fonts are traced into the serverless bundle (`outputFileTracingIncludes`).
